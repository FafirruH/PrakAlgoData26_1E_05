## Pertanyaan
1. Single Linked List hanya memiliki pointer next sehingga traversal hanya dapat dilakukan dari depan ke belakang, sedangkan Double Linked List memiliki pointer next dan prev sehingga traversal dapat dilakukan dua arah.
2. Atribut next berfungsi menunjuk node berikutnya untuk traversal maju, sedangkan prev berfungsi menunjuk node sebelumnya untuk traversal mundur dan mempermudah manipulasi node.
3. Konstruktor pada class DoubleLinkedList berfungsi untuk menginisialisasi linked list dalam keadaan kosong dengan nilai head dan tail sama dengan null.
4. Saat linked list masih kosong, head dan tail harus menunjuk node yang sama karena node tersebut menjadi node pertama sekaligus node terakhir.
