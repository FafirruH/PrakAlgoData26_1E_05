## Pertanyaan
1. Front dan rear bernilai -1 untuk menandakan queue masih kosong, sedangkan size bernilai 0 karena belum ada data.
2. Method enqueue digunakan untuk menambahkan data ke belakang queue dengan mengatur posisi rear dan menambah jumlah elemen.
3. Method dequeue digunakan untuk mengambil dan menghapus data dari depan queue dengan menggeser posisi front dan mengurangi jumlah elemen.
4. Perulangan dimulai dari front karena posisi awal data dalam queue bisa bergeser dan tidak selalu dimulai dari indeks 0.
5. Perulangan dari front sampai rear bertujuan untuk menampilkan semua data yang masih ada di dalam queue secara berurutan.
