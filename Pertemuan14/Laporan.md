## Pertanyaan
1. dataMahasiswa sebagai Tempat menyimpan semua data mahasiswa dalam bentuk array. Posisi indeksnya menentukan letak node dalam tree. idxLast sebagai Penanda batas akhir data yang valid dalam array. Digunakan agar program tahu kapan harus berhenti saat melakukan traversal.
2. Untuk memasukkan data mahasiswa dari luar (dari main()) ke dalam class BinaryTreeArray.
3. Untuk menampilkan semua data mahasiswa dalam tree secara berurutan, dengan pola: kiri, tengah, kanan. Hasilnya data tampil dari urutan pertama hingga terakhir sesuai posisi dalam tree.
4. Left child 2x2+1=5. Right child 2x2+2=6
5. Untuk membatasi rekursi agar tidak terus berjalan melewati data yang ada.
6. Indeks 2 * idxStart + 1 dan 2 * idxStart + 2 digunakan karena pada representasi Binary Tree menggunakan array, hubungan parent–child ditentukan berdasarkan posisi indeks array, bukan menggunakan pointer seperti pada linked list. Rumus ini merupakan aturan standar penyimpanan binary tree secara level-order di array. Karena setiap node memiliki maksimal dua anak, posisi anak dapat dihitung langsung dari indeks parent, sehingga traversal rekursif dapat menelusuri struktur pohon meskipun data hanya disimpan dalam array.
